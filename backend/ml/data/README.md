# Data Directory — Multi-Hazard Early Warning System (Sikkim)

This directory stores the prototype synthetic training data and explains the integration path for real meteorological, satellite, and GIS data sources.

---

## 1. Prototype Dataset: `prototype_training_data.csv`

The prototype dataset is automatically generated by `ml/src/data_loader.py` if not already present.

- **Sample count:** 5,000 rows
- **Class distribution:** 400 positives (`landslide_occurred = 1`, 8%), 4,600 negatives (`landslide_occurred = 0`, 92%)
- **Missing value simulation:** 5–10% missing values (NaN) injected across numerical features to simulate real sensor and satellite transmission gaps.
- **Geographic bounding box:** Sikkim, Eastern Himalayas (Lat 27.0°N – 28.1°N, Lon 88.0°E – 89.0°E)
- **Temporal span:** 2018-01-01 to 2023-12-31 with realistic monsoon seasonal clustering.

## 2. Real Data Source Replacement Guide

When transitioning from the prototype to operational deployment, each synthetic feature maps to official authoritative datasets:

| Feature Name | Prototype Generator | Operational Data Source | Retrieval & Processing Method |
|---|---|---|---|
| `rainfall_30min_mm` | Gamma distribution | **NASA GPM IMERG Early Run** | ~4 hr latency, 0.1° grid, retrieved via NASA Earthdata API |
| `rainfall_3hr_mm` | Derived rolling window | NASA GPM IMERG | 3-hour cumulative sum of IMERG half-hourly grids |
| `rainfall_24hr_mm` | Derived rolling window | NASA GPM IMERG / IMD AWS | 24-hour cumulative sum; calibrated against IMD station data |
| `rainfall_3day_mm` | Derived rolling window | NASA GPM IMERG | 72-hour cumulative sum |
| `rainfall_7day_mm` | Derived rolling window | NASA GPM IMERG | 7-day cumulative sum for antecedent soil saturation tracking |
| `rainfall_intensity` | `rainfall_30min / 0.5` | Derived | mm/hour equivalent rate |
| `antecedent_rainfall_anomaly` | Deviation from 80mm | **IMD 30-Year Normals** | 7-day IMERG total minus pixel-wise climatological mean |
| `soil_moisture_pct` | Beta distribution | **IoT Capacitive Sensors / NASA SMAP** | Ground telemetry via ESP32 (`POST /api/v1/sensor-data`) or SMAP 9km L4 product |
| `soil_moisture_change_rate` | Normal distribution | Derived from IoT readings | Hourly rate of change: `(SM_t - SM_{t-1}) / delta_t` |
| `elevation_m` | Uniform distribution | **SRTM 30m / ALOS PALSAR DEM** | Elevation above mean sea level processed via GDAL/rasterio |
| `slope_deg` | Normal / Gamma | Derived from DEM | Horn's algorithm slope gradient in degrees (0–90°) |
| `aspect_deg` | Uniform (0–360°) | Derived from DEM | Terrain aspect direction in degrees (0–360°) |
| `ndvi` | Beta distribution | **Sentinel-2 L2A** | `(Band 8 - Band 4) / (Band 8 + Band 4)` via Copernicus Data Space / GEE |
| `land_cover_class` | Categorical choice | **ESA WorldCover 10m / Sentinel-2** | 10m land use/land cover classification (forest, bare, agri, built) |
| `historical_landslide_density` | Poisson / Neg-Binomial | **ISRO Landslide Atlas of India** | Spatial join count of past events (1998–2022) within 5 km radius |
| `distance_to_river_km` | Exponential | **OpenStreetMap / Bhuvan Drainage** | Euclidean distance to nearest perennial or seasonal stream vector |
| `distance_to_road_km` | Exponential | **OpenStreetMap / BRO Highway Network** | Euclidean distance to cut slopes along national highways and roads |
| `tilt_change_deg` | Exponential / Normal | **IoT Inclinometer (MPU6050)** | Cumulative angular displacement from baseline installed on active slope |
| `temperature_C` | Normal distribution | **IMD AWS / ERA5-Land** | Surface 2m air temperature (°C) |
| `data_freshness_score` | Categorical tag | System latency calculation | FRESH (1.0) / RECENT (0.7) / STALE (0.4) / MISSING (0.0) |

## 3. Adding Real Training Data

To replace the prototype synthetic data with real data:
1. Place the historical feature table formatted as CSV in `ml/data/prototype_training_data.csv` (or specify a custom path in `ml/src/config.py`).
2. Verify all columns match the names in `ml/src/config.py` (`RAWFEATURE_NAMES`).
3. Re-run training:
   ```bash
   python ml/run_training.py
   ```
